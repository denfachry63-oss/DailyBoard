# DailyBoard
 Fitur
- Mode terang/gelap
- Kutipan motivasi harian (refresh manual)
- Cek cuaca berdasarkan kota
- Manajemen tugas: tambah, edit, hapus, selesai, cari, filter, drag-and-drop urutan
- Catatan: tambah, edit, hapus
- Auto-save ke localStorage
Cara Pakai
Klik ikon 🌙/☀️ untuk ganti tema
Klik ↻ Refresh untuk ganti kutipan
Ketik nama kota → klik "Cari Cuaca"
Ketik tugas → Enter atau klik "Tambah"
Klik judul tugas untuk tandai selesai
Klik "Edit"/"Hapus" pada tugas atau catatan
Seret (drag) tugas untuk ubah urutan
Ketik di kolom cari untuk filter tugas
Klik "Semua"/"Selesai"/"Belum Selesai" untuk filter status
Tulis catatan → klik "Tambah"
Double-click catatan untuk edit langsung
